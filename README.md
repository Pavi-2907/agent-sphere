# AgentSphere

AI-Powered Multi-Agent Career Intelligence Platform.

## Overview

AgentSphere is a multi-agent AI platform designed to provide intelligent assistance for career development, coding practice, resume analysis, and interview preparation.

## Planned Features

- Multi-agent orchestration
- AI-powered career guidance
- Coding assistance
- Resume analysis
- Interview preparation
- Retrieval-Augmented Generation (RAG)
- Agent memory
- Model Context Protocol (MCP) integration

## Technology Stack

- Python
- FastAPI
- Large Language Models (LLMs)
- RAG
- MCP
- Git and GitHub
